# SenseVoice 与全量清空队列审查报告

- 日期：2026-08-17
- 执行者：Codex

## 结论

- 模型下载与媒体下载使用不同线程池，设置窗口仅观察服务状态，不拥有后台任务生命周期。
- 下载状态与转写状态分离；媒体成功后即使转写失败，记录仍按媒体成功处理并提供转写重试。
- 清空队列以数据库非历史状态和后端活动任务的 ID 并集为准，界面筛选只负责显示。
- 数据库迁移为可重复执行的增量列迁移，现有记录默认不请求转写。
